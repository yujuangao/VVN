VVN Insight

Scaffold and build a complete VVN narrative report.

The create_vvn_story() function scaffolds a complete Quarto narrative report in one command. The analysis and the narrative are kept in separate files so each is easier to work on independently.

Required libraries

Install before running create_vvn_story():

# index.qmd (rendered by Quarto) — required
install.packages(c("knitr", "dplyr", "readr", "gt"))

# scripts/analysis.R — required
install.packages(c("ggplot2", "dplyr", "tidyr"))

# Optional — uncomment in analysis.R or index.qmd when needed
install.packages(c("leaflet", "sf", "mapshot2"))

vvnthemes is required in both files and is loaded automatically by the scaffold.

Library Used in What it does
knitr index.qmd Embeds figure PNGs in the narrative using include_graphics() in Quarto chunks
dplyr both Data manipulation: filter(), select(), mutate(), summarise()
readr analysis.R Fast CSV loading with read_csv()
gt index.qmd Styled summary tables — pairs with vvn_table() for VT-branded headers
ggplot2 analysis.R Build all static charts saved as PNGs to figures/
tidyr analysis.R Reshape data between wide and long formats
leaflet analysis.R Build interactive county choropleth maps (optional)
sf analysis.R Read and process spatial data (.geojson, .shp) — required with leaflet
mapshot2 analysis.R Save a Leaflet map as a static PNG for embedding in the story

Create the project

library(vvnthemes)
create_vvn_story(
  "my-insight",
  title    = "Broadband Access in Rural Virginia",
  subtitle = "County-Level Trends from the ACS",
  author   = "VVN Research Team"
)

Project structure

my-insight/
├── index.qmd            # Narrative — .finding sections with PNG + iframe options
├── _quarto.yml          # Quarto configuration
├── styles.scss          # VVN brand styles (Pew Research–inspired, do not edit)
├── assets/              # Interactive HTML maps/widgets (embedded via iframe)
├── data/
│   ├── raw/             # Place raw data files here
│   └── processed/       # Place cleaned / analysis-ready data here
├── scripts/
│   └── analysis.R       # Build figures + save interactive maps, then run
└── figures/             # Static PNG charts — auto-created when analysis.R runs

What each file does

scripts/analysis.R is where you write all chart code. It loads your data, builds each figure using VVN functions, and saves numbered PNGs to figures/ automatically. It also documents how to save interactive HTML maps to assets/. Run this script first, before opening index.qmd.

index.qmd is the narrative document. It uses the VVN Insights article structure with .vvn-header, .vvn-stats-row, .finding-statement headlines, and <details class="about-research"> collapsible sections. Each finding section provides two options for visuals:

  • Static PNG: knitr::include_graphics("figures/01_name.png") — generated by analysis.R
  • Interactive HTML: .map-card iframe block pointing to assets/map.html — pre-built or saved via htmlwidgets::saveWidget()

figures/ is populated automatically when you run scripts/analysis.R. Files are named 01_, 02_, … in the order the script runs them.

assets/ holds interactive HTML maps and widgets (Leaflet, Folium, Plotly, geemap). These are embedded in index.qmd using the .map-card + <iframe> pattern. You can place pre-built HTML files here directly, or save them from R:

library(leaflet); library(htmlwidgets)
m <- leaflet(va_counties) |> vvn_map_style(va_counties, "value")
saveWidget(m, "assets/01_map.html", selfcontained = TRUE)

data/raw/ holds your original data files unchanged. data/processed/ holds cleaned, analysis-ready files. Load processed files in scripts/analysis.R.

_quarto.yml configures the Quarto project: theme, TOC settings, figure dimensions, and output format. You rarely need to edit this file.

styles.scss is the VVN brand stylesheet (Pew Research Center–inspired). Do not edit this file.

Document structure

Section Element Required
Header ::: {.vvn-header} with .vvn-rubric, .vvn-tag, .vvn-subtitle, .vvn-byline Yes
Key statistics ::: {.vvn-stats-row} with .vvn-stat boxes (gold big numbers) Yes
About This Research <details class="about-research"> collapsible (Background, Data & Methods, Limitations) Yes
Findings ## Title {.finding} + ::: {.finding-statement} + figure/map Yes (at least 1)
Conclusion ## Conclusion {.unnumbered} Yes

Each finding section supports two visual options:

  • Static figure: knitr::include_graphics("figures/01_name.png")
  • Interactive map: ::: {.map-card} + <iframe src="assets/map.html"> + ::: {.map-caption}

For section requirements, narrative rules, and publishing checklist, see VVN Insights Standards →

Workflow

Follow these three steps in order:

Step 1 — Build figures and maps

Open scripts/analysis.R in RStudio and fill in your chart code. The script contains a gallery of common VVN chart types — uncomment the ones you need and fill in your column names and labels. For interactive maps, save HTML files to assets/ using htmlwidgets::saveWidget(). Then source the script:

# In RStudio: open scripts/analysis.R, then click Source
# Or from the R console:
source("scripts/analysis.R")

Static figures are auto-numbered (01_, 02_, …) and saved to figures/. Interactive HTML maps go in assets/.

Step 2 — Write the narrative

Open index.qmd. Replace every [placeholder] with your content. For each finding section, choose one of two visual options:

Option A — Static PNG figure:

# In index.qmd — replace [name] with your actual figure filename:
f <- "figures/01_trend_statewide.png"
if (file.exists(f)) knitr::include_graphics(f)

Option B — Interactive HTML map (iframe):

::: {.map-card}
<iframe src="assets/01_map.html" height="580"
  style="width:100%;border:none;" title="Map title"></iframe>
::: {.map-caption}
**Figure 1.** Caption describing the map.
[Source: Dataset name]{.vvn-source}
:::
:::

The file.exists() guard on static figures means index.qmd renders without errors even if some figures are not yet built — missing figures simply leave a blank space.

Step 3 — Render

quarto::quarto_render("index.qmd")

In RStudio, press Cmd+Shift+K (Ctrl+Shift+K on Windows).

## Publishing checklist

Before submitting a VVN Insight for publication:

- [ ] `scripts/analysis.R` runs without errors and all figures appear in `figures/`
- [ ] All `[...]` placeholders in `index.qmd` replaced
- [ ] Figure filenames inside `f <- "figures/..."` match actual files, or `.map-card` iframe `src` paths point to existing files in `assets/`
- [ ] `.vvn-header` present with title, subtitle, rubric, tags, and byline
- [ ] `.vvn-stats-row` with 3–4 key statistics
- [ ] `<details class="about-research">` section with Background, Data & Methods table, and Limitations
- [ ] At least 1 `.finding` section with `.finding-statement` headline
- [ ] At least 2 visuals (charts or interactive maps) with source lines
- [ ] `vvn_source()` on every static figure; `[Source: ...]{.vvn-source}` on every `.map-caption`
- [ ] Conclusion section present
- [ ] All chart titles use headline case
- [ ] All chart subtitles use sentence case
- [ ] `embed-resources: true` in YAML (single-file HTML)
- [ ] `check_vvn_story()` passes
